## 🤯 WHAT IS THIS MADNESS?!

Welcome to **ServiceHub**! 🌍 It's not just an app, it's an **EXPERIENCE**! Need a plumber? 🪠 Got a leaky faucet? 💧 Want someone to mow your lawn while you sip margaritas? 🍹 **WE GOT YOU COVERED!** 

ServiceHub is a blazing fast ⚡, ultra-modern 🎨, full-stack MERN application that seamlessly connects **Service Providers** 👷‍♂️ with **Customers** 🧑‍💻. Say goodbye to endless phone calls and say HELLO to instant bookings! 📅✨

---

## 🌟 SUPERCHARGED FEATURES 🌟

- **🎭 Dual Roles:** Sign in as a `Customer` to find services or as a `Provider` to make that paper! 💸
- **🔍 Smart Search & Match:** Can't find what you need? Our smart filters got your back! 🧠
- **🛠️ Provider Dashboard:** Manage your hustle! Create services, set your prices, and track your incoming bookings like a boss! 📈
- **💳 Razorpay Integration:** Secure, blazing-fast checkouts! Cha-ching! 💰
- **🌙 Beautiful UI/UX:** Built with TailwindCSS and Next.js for that buttery smooth user experience! 🧈
- **🔐 Secure Auth:** Your data is locked up tighter than Fort Knox! 🏰

## 🚀 HOW TO IGNITE THIS ROCKET 🚀

Ready to run this beast locally? Follow these steps, and don't skip leg day! 💪

### 1️⃣ Clone the Repo
```bash
git clone https://github.com/Atharva6153-git/Booking.git
cd Booking/servicehub
```

### 2️⃣ Start the Backend Engine 🚂
```bash
cd backend
npm install
npm run dev
# 🔥 Backend is now breathing fire on localhost:5000 🔥
```

### 3️⃣ Fire up the Frontend UI 🎆
```bash
cd ../frontend
npm install
npm run dev
# 🚀 Frontend is now blasting off on localhost:3000 🚀
```
